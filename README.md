# StudentHub Portal

## Project Overview

StudentHub Portal is a simple HTML project developed for learning basic web development concepts. It provides different web pages that help students access academic information such as courses, assignments, timetable, announcements, profile, and contact details.

## Technologies Used

* HTML5
* Inline CSS
* Basic JavaScript

## Features

* Home page with project introduction
* Student Login page
* Student Registration page
* Dashboard with student information
* Profile page
* Courses page
* Assignments page
* Announcements page
* Timetable page
* Contact page

## Folder Structure

* index.html
* login.html
* register.html
* dashboard.html
* profile.html
* courses.html
* assignments.html
* announcements.html
* timetable.html
* contact.html

## How to Run

1. Download or copy all project files into one folder.
2. Open the folder.
3. Double-click **index.html** or open it in any web browser.
4. Use the navigation menu to visit other pages.

## Project Highlights

* Simple and easy-to-understand user interface.
* Navigation between all pages using hyperlinks.
* Basic inline CSS for page styling.
* Basic JavaScript alerts used on Login, Register, and Contact pages.
* Semantic HTML tags such as **header**, **nav**, **main**, **section**, and **footer** are used for better page structure.

## Purpose

The purpose of this project is to understand the basics of HTML, inline CSS, JavaScript, forms, tables, hyperlinks, images, and semantic HTML tags by creating a simple student portal.
