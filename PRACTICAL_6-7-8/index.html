Welcome to StudentHub Portal

StudentHub is an academic portal designed for students. Check courses, events, student profiles, FAQs, assignments, timetable, and announcements with modern web features.

Portal Features & Laboratory Work

  • Practical 6: Fetch API Dynamic Rendering - External JSON Data (events.json, students.json, faqs.json), Multi-Attribute Search, Filter, Sort, Pagination, Dependent Dropdowns (Country/State/City), and Offline LocalStorage Caching.
  • Practical 7: PHP Form Processing - Server-Side Input Validation, Sanitization, CSRF Token Security, Safe CSV & JSON File Writing, and Interactive Records Viewer (view_records.php).
  • Practical 8: MySQL Database Integration - Reusable PDO Connection (db.php), Relational Schema (students, events, registrations), Prepared Statements (INSERT, SELECT), Foreign Keys with ON DELETE/UPDATE CASCADE, and Multi-Table SQL INNER JOIN.
  • Student Profile Management & Real-Time Local Storage Sync
  • Course Catalog Explorer with Department Filtering
  • Assignments, Timetable, and Announcements
