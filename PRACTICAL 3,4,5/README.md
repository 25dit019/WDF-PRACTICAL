# Practical 2 – StudentHub Portal

## Objective
To design and develop a multi-page StudentHub Portal using only HTML and CSS.

## Technologies Used
- HTML5
- CSS3

## Features
- Home Page
- Login Page
- Registration Page
- Dashboard
- Student Profile
- Courses Page
- Assignments Page
- Announcements Page
- Timetable Page
- Contact Page
- Responsive and Clean User Interface
- Navigation Between Pages

## Files Included
- index.html
- login.html
- register.html
- dashboard.html
- profile.html
- courses.html
- assignments.html
- announcements.html
- timetable.html
- contact.html
- style.css
- login.css
- register.css
- dashboard.css
- profile.css
- courses.css
- assignments.css
- announcements.css
- timetable.css
- contact.css

## Learning Outcomes
- Learned to create a multi-page website using HTML.
- Learned to apply CSS for styling web pages.
- Understood website structure and page navigation.
- Improved skills in layout design and UI development.
- Gained experience in organizing project files.

## Challenges Faced
- Maintaining consistent design across all pages.
- Managing multiple HTML and CSS files.
- Creating proper navigation between pages.
- Organizing project folders and files.

## Conclusion
This practical helped in understanding the basics of web development by building a StudentHub Portal using only HTML and CSS. It improved knowledge of webpage structure, styling, navigation, and project organization.
